# Tic-Tac-Toe (איקס עיגול)

משחק איקס עיגול לשני שחקנים בטרמינל, ב-Python.

## דרישות

- Python 3

## הרצה

```bash
python tictactoe.py
```

או:

```bash
python3 tictactoe.py
```

## איך משחקים

שני שחקנים משחקים לסירוגין על לוח 3x3:

- שחקן **X** מתחיל
- בכל תור בוחרים שורה ועמודה (מספרים 1–3)
- מנצח מי שמשלים שורה, עמודה או אלכסון
- אם הלוח מתמלא בלי ניצחון — המשחק מסתיים בתיקו

קלט לא חוקי (מספר מחוץ לטווח, תא תפוס, או טקסט שאינו מספר) נדחה, והשחקן מתבקש לנסות שוב.

## קבצים

- `tictactoe.py` — לוגיקת המשחק והממשק בטרמינל
